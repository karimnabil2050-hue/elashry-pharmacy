# تطبيق الصيدلية — خطوات التشغيل

تطبيق واحد فيه حاجتين: **العميل** (يطلب الدوا) و**قسم التجميل والعروض**
- منتجات مقسمة: عناية بالبشرة، شعر، مكياج، عطور، واقي شمس، أطفال
- شريط عروض بيلف لوحده، وشارة الخصم بتتحسب تلقائيًا
- بحث، وسلة، والطلب بيروح للصيدلي يأكد التوفر والتوصيل

**الخريطة**
- العميل يحدد مكان التوصيل على الخريطة (أو موقعه الحالي بالـ GPS)
- الصيدلي يشوف المكان على خريطة صغيرة ويفتحه في خرائط جوجل

**الصيدلي** (يستقبل الطلبات ويرد بالسعر).
التطبيق بيعرف مين الداخل من نوع الحساب.

مبني بـ Flutter + Firebase، وشغال على **باقة Firebase المجانية** (Spark) من غير أي دفع.

---

## اللي جوه التطبيق

**العميل**
- دخول برقم الموبايل + كلمة سر
- يصوّر الروشتة أو يختار صورة أو يكتب طلبه
- يستلم عرض السعر من الصيدلي ويوافق أو يلغي
- يتابع الطلب بشريط تتبع: استلمنا ← مراجعة ← عرض السعر ← تجهيز ← في الطريق ← وصل
- تنبيه جوه التطبيق مع كل تغيير في حالة الطلب
- **أدويتي المزمنة**: يضيف دوا الضغط/السكر، والتطبيق يحسب إمتى العلبة هتخلص وينبّهه قبلها بـ 5 أيام ويطلبها بضغطة
- يعيد أي طلب قديم بضغطة
- زرار يكلّم الصيدلية مباشرة

**الصيدلي**
- لوحة فيها الطلبات مقسمة: جديدة / مستني العميل / تجهيز وتوصيل / منتهية
- صوت واهتزاز مع كل طلب جديد أو موافقة عميل
- الطلب اللي مستني أكتر من 10 دقايق بيتعلّم بالأحمر
- يشوف الروشتة ويكبّرها، ويكلّم العميل بضغطة
- يكتب عرض السعر (صنف + عدد + سعر + توصيل) مع ردود جاهزة
- يحرّك الطلب: بدأ التجهيز ← خرج مع المندوب ← اتسلم
- إحصائيات النهارده: عدد الطلبات واللي اتسلم والمبيعات
- أيقونة ✿ فوق: يضيف ويعدّل منتجات التجميل والعروض بالصور (وفيه زرار يضيف منتجات تجريبية)

## خطوات التشغيل على ويندوز

> التطبيق **مربوط خلاص** بمشروع Firebase بتاعك (pharmacy-a93c7)، ومش محتاج `firebase login` ولا `flutterfire configure`.
> ⚠️ **قواعد الأمان اتغيّرت في النسخة دي** (عشان المنتجات والموقع): انسخ محتوى `firestore.rules` والصقه في Firebase Console ← Firestore ← Rules ← **Publish**.

### 1. فك الملف
- امسح فولدر `pharmacy_app` القديم خالص.
- فك `pharmacy_app.zip` **على الديسكتوب مباشرة** (مش جوه `New folder`)، عشان المسافة في اسم الفولدر بتعمل مشاكل.
- افتح فولدر `pharmacy_app` في VS Code: File ← Open Folder.

### 2. حمّل المكتبات
```
flutter pub get
```

### 3. تأكد إن الدخول بالإيميل مفعّل
Firebase Console ← Authentication ← Sign-in method ← **Email/Password** = Enabled

### 4. شغّل على الويب
```
flutter run -d chrome
```

### 5. شغّل على موبايل أندرويد
وصّل الموبايل بالكابل (USB debugging مفعّل) واكتب:
```
flutter run
```

### 6. غيّر اسم الصيدلية ورقمها
افتح `lib/theme.dart` وغيّر `pharmacyName` و `supervisor` و `pharmacyPhone`،
و `pharmacyLat` / `pharmacyLng` (مكان الصيدلية: الخريطة بتفتح عليه لو الموبايل مقدرش يحدد الموقع).

### 7. اعمل حساب الصيدلي
1. من التطبيق اعمل حساب جديد عادي برقم الصيدلي
2. في Firebase Console ← Firestore ← `users` ← افتح المستند بتاع الحساب ده
3. غيّر `role` من `customer` لـ `pharmacist`
4. اقفل التطبيق وافتحه تاني ← هتلاقي لوحة الصيدلي

(التطبيق نفسه مش بيسمح لحد يخلّي نفسه صيدلي، دي بتتعمل من الكونسول بس.)

### 8. طلّع ملف APK تنزّله على أي موبايل

```
flutter build apk --release
```

الملف هيكون في: `build\app\outputs\flutter-apk\app-release.apk`

## الآيفون (iOS)

الكود واحد للأندرويد والآيفون. الإعدادات الجاهزة:
- اسم التطبيق والأيقونة وشاشة البداية
- أذونات الكاميرا والصور والموقع بالعربي
- iOS 15 أو أحدث (مطلوب لـ Firebase)
- Bundle ID: `com.pharmacy.pharmacyApp`

**عشان يتبني ويترفع محتاج:**
1. جهاز ماك فيه Xcode، **أو** حساب مجاني على **codemagic.io** (الملف `codemagic.yaml` جاهز)
2. حساب Apple Developer (99 دولار في السنة) للتوقيع والرفع على App Store / TestFlight

```
dart run flutter_launcher_icons
dart run flutter_native_splash:create
```

## جرّبه كده (سيناريو كامل)
محتاج موبايلين (أو موبايل + محاكي):
1. موبايل العميل: اعمل حساب ← صوّر أي ورقة ← ابعت الطلب
2. موبايل الصيدلي: هيرن ويظهر الطلب ← افتحه (العميل هيشوف "جاري المراجعة") ← اكتب صنفين بأسعارهم ← ابعت السعر
3. العميل: هيظهر له السعر ← وافق
4. الصيدلي: بدأت التجهيز ← خرج مع المندوب ← اتسلم
5. العميل: شريط التتبع هيتحرك مع كل خطوة

## حاجات لازم تعرفها
- **التنبيهات جوه التطبيق بس**: الصوت والرسالة بيشتغلوا والتطبيق مفتوح. إشعارات الموبايل وهو مقفول محتاجة باقة Blaze (Cloud Functions)، ودي ممكن نضيفها بعدين.
- **صورة الروشتة** بتتحفظ مضغوطة جوه Firestore نفسها (حوالي 150–300 كيلو للصورة) عشان منحتاجش Firebase Storage المدفوع. الباقة المجانية فيها 1 جيجا، يعني آلاف الروشتات.
- **رقم الموبايل مش متأكد بـ SMS**. عشان كده الصيدلي بيكلّم العميل قبل أول توصيل لو شاكك.
- **نسيان كلمة السر**: مفيش استرجاع تلقائي. الحل: من Firebase Console ← Authentication امسح الحساب، والعميل يسجّل تاني بنفس الرقم.
- **الأدوية اللي محتاجة روشتة**: الصيدلي هو اللي بيقرر. فيه رد جاهز "الدوا ده محتاج روشتة أصلية تتسلم للمندوب".

## هيكل الملفات

```
lib/
  main.dart                    بداية التطبيق (عربي ومن اليمين للشمال)
  theme.dart                   الألوان واسم الصيدلية ورقمها
  firebase_options.dart        إعدادات ربط Firebase (ويب + أندرويد)
  models/                      الطلب، المستخدم، الدوا المزمن
  services/
    auth_service.dart          الدخول والتسجيل برقم الموبايل
    order_service.dart         كل التعامل مع قاعدة البيانات
    image_service.dart         تصوير وضغط الروشتة
  screens/
    root_gate.dart             يحدد يفتح شاشة العميل ولا الصيدلي
    auth/                      الدخول وحساب جديد
    customer/                  الرئيسية، طلب جديد، طلباتي، تفاصيل الطلب، أدويتي، حسابي
    pharmacist/                لوحة الصيدلي وشاشة الطلب وعرض السعر
  widgets/common.dart          شريط التتبع، صورة الروشتة، جدول السعر
firestore.rules                قواعد الأمان
test/logic_test.dart           اختبارات الحسابات (flutter test)
```
